# Home Automation UI

A application for home automation to allow users to setup schedule or manually control home automation devices located in each room of a household.

## Commands

- `npm run dev` — start the dev server at http://localhost:3000
- `npm run build` — production build (also runs type checking)
- `npm run start` — serve the production build
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`, Next core-web-vitals + TypeScript rules)
- `npx tsc --noEmit` — type check without building

No test framework is set up yet.
